# Rahul Taneja — Portfolio

Modern, responsive developer portfolio built with React, TypeScript and Vite.

## Stack

- React 19
- TypeScript
- Vite
- Responsive CSS
- Accessible interactions
- Light / dark theme
- Render-ready static deployment

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The repository includes `render.yaml` for a separate Render static-site deployment.

GitHub: https://github.com/RTdeveloper2
